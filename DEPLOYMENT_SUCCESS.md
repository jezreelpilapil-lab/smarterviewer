## 📝 Customization Tips

### Change Colors
Edit `webapp/styles.css`:
```css
:root {
    --primary-color: #e50914;  /* Your brand color */
}
```

### Add Your Content
Edit `webapp/app.js`:
```javascript
const sampleMovies = [
    {
        title: "Your Movie",
        videoUrl: "https://your-video.mp4",
        thumbnail: "poster.jpg",
        // ...
    }
];
```

### Use TMDb API (Free Movies)
1. Get API key: https://www.themoviedb.org/settings/api
2. Update the `loadTMDbContent()` function in `webapp/app.js`

## 🆘 Troubleshooting

### If site shows 404:
- Ensure GitHub Pages is enabled in Settings
- Wait 5 minutes after enabling
- Check the branch is `main` and folder is `/webapp`

### If favicon doesn't show:
- Clear browser cache (Ctrl+Shift+Delete)
- Hard refresh (Ctrl+Shift+R)

### If you need to update:
```bash
git add .
git commit -m "Your update message"
git push origin main
```
